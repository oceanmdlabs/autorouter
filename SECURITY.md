# Security Policy

## Supported Versions

Ocean Autorouter is under active development. Security fixes are applied to the
latest code on the `main` branch. Older commits, forks, and unmaintained
deployments are not supported.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/oceanmdlabs/autorouter/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected component, impact, reproduction steps, and any suggested
mitigation. Use synthetic or de-identified data only. Never include patient
health information, production credentials, shared encryption keys, access
tokens, or other secrets in a report or attachment.

The maintainers will acknowledge the report, investigate it, and coordinate
remediation and disclosure with the reporter. Please allow a reasonable period
for a fix to be developed and deployed before public disclosure.

## Operational Incidents

This repository's vulnerability-reporting channel is not an emergency or
clinical-support service. Handle suspected exposure of patient information or
production credentials through the organization's established privacy,
security, and incident-response procedures immediately.
