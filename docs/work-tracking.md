# Work tracking

After cutover, code and pull requests belong in [OceanMD Bitbucket](https://bitbucket.org/oceanmd/autorouter/src/main/). [GitHub Issues](https://github.com/oceanmdlabs/autorouter/issues) remains the project work tracker during the transition. Search for an existing issue before filing a new request. Link the issue from the Bitbucket pull request and record verification, deployment, and acceptance in the issue.

The GitHub repository must remain unarchived while its Issues tracker is in use. Do not open new GitHub pull requests or push new development code there after Bitbucket becomes active. If a replacement tracker is chosen later, move open issues with their bodies and source links and verify the new records before considering archival.
